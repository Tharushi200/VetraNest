# VetraNest™ | Veterinary Clinic & Pet Care Management System

An enterprise-grade Desktop Information System engineered for modern Veterinary Clinics, Animal Hospitals, and Pet Wellness Centers.

Built with **Java Swing (FlatLaf Modern UI)**, **MySQL 8 (Singleton Pattern + PreparedStatements)**, and **JasperReports 6.21 (4-Table JOIN Multi-Reports)** following the **3-Tier / MVC + DAO Architectural Pattern**.

Developed for **NIBM Higher National Diploma in Software Engineering / Computing - Enterprise Application Development I (EAD 1)**.
